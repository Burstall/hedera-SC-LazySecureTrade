## 🏗️ Architecture Overview

### **Bidder Factory Pattern**
```
LazySecureTrade (Core) ←→ BidderContractFactory ←→ Individual BidderContracts
                                    ↓
                            LazyGasStation (Gas Abstraction)
```

**Benefits**:
- **Isolation**: Each bidder strategy operates independently
- **Scalability**: Unlimited bidding strategies via factory cloning
- **Gas Efficiency**: Shared gas station for transaction cost management
- **Security**: Sandboxed execution with controlled permissions

### **Integration Points** 
v0.2 provides complete hooks:
- ✅ Trade discovery via `getTokenTrades()` and `getTradesForToken()`
- ✅ Atomic execution via `executeTrades()` (5-trade limit)
- ✅ Fee transparency via `calculateSellerFeeRate()`
- ✅ Event monitoring for automated strategies

## 📋 Phase 1: Core Bidder Infrastructure (4-6 weeks)

**Foundation**: Implement CLOB-style bidding with LazySecureTrade integration

### **Architecture Overview**
```
EOAs ←→ BidderContractFactory ←→ LazySecureTrade (Trade Creation/Execution)
           ↓                              ↓
    BidderContract[] (Honeypots)     Event Tracking & Fees
           ↓
    TokenStakerV2 (NFT Withdrawal)
```

### **Core Contracts**

#### **1. BidderContractFactory.sol (Central Router)**
```solidity
contract BidderContractFactory {
    // User honeypot mapping (1:1 relationship)
    mapping(address => address) public userToBidderContract;
    
    // CLOB discovery (token-based bid lookup)
    mapping(address => bytes32[]) public tokenToBids;
    mapping(bytes32 => BidDetails) public bidRegistry;
    
    // Deploy user's BidderContract
    function deployBidderContract() external returns (address);
    
    // Create bid (called via BidderContract)
    function createBid(BidDetails memory bidDetails) external returns (bytes32 bidId);
    
    // Execute against bid (seller-initiated)
    function executeAgainstBid(bytes32 bidId, address nftToken, uint256 serial) external;
    
    // Third-party arbitrage
    function executeArbitrage(bytes32 bidId, bytes32 existingTradeId) external;
    
    // CLOB discovery
    function getBidsForToken(address token) external view returns (bytes32[]);
    function isBidValid(bytes32 bidId) external view returns (bool, string memory);
}
```

#### **2. BidderContract.sol (User Honeypot)**
```solidity
contract BidderContract {
    address public owner;           // User sovereignty
    address public factory;         // Admin rights for arbitrage only
    uint256 public nonce;          // Bid uniqueness
    
    // Fund management (HTS native transfers)
    function withdrawHbar(uint256 amount) external onlyOwner;
    function factoryWithdrawHbar(uint256 amount) external onlyFactory;  // Arbitrage profits
    
    // Bid creation (with automatic token association)
    function createBid(address token, uint256[] serials, uint256 hbarAmount, uint256 expiry) external onlyOwner;
    
    // Token association (internal, triggered during bidding)
    function _associateTokenIfNeeded(address token) internal;
    
    // NFT withdrawal via TokenStakerV2 pattern (multi-token support)
    function withdrawNFTs(address[] tokens, uint256[][] serials) external onlyOwner;
    
    // Event emission with factory consolidation
    function _emitFactoryEvent(EventType eventType, bytes memory eventData) internal;
}
```

#### **3. LazySecureTrade Integration (Minimal Changes)**
```solidity
// Single addition to existing contract
mapping(address => bool) public authorizedFactories;

function createTradeOnBehalf(address seller, address buyer, ...) external returns (bytes32) {
    require(authorizedFactories[msg.sender], "Unauthorized");
    // Create trade with seller = EOA, buyer = BidderContract
    // Reuse all existing trade logic
}
```

### **Execution Flows**

#### **Flow 1: Seller Executes Against Bid**
1. **Seller discovers bid** via `getBidsForToken(token)` 
2. **Seller calls** `executeAgainstBid(bidId, nftToken, serial)`
3. **Factory validates** bid and creates trade via `LazySecureTrade.createTradeOnBehalf()`
4. **Factory executes** trade via `BidderContract.executeTrade()`
5. **LazySecureTrade processes** with all existing logic (fees, events)
6. **Factory cleans up** bid registry and emits events

#### **Flow 2: Third-Party Arbitrage**
1. **Arbitrageur identifies** profitable bid + existing trade
2. **Arbitrageur calls** `executeArbitrage(bidId, existingTradeId)`
3. **Factory executes** trade and calculates profit
4. **Factory splits** 50% to arbitrageur, 50% to factory
5. **Factory extracts** profits via `BidderContract.factoryWithdrawHbar()`

#### **Flow 3: User Bid Creation**
1. **User calls** `BidderContract.createBid(token, serials, amount, expiry)`
2. **BidderContract validates** funds and calls factory
3. **Factory creates** bid hash and updates registries
4. **Factory emits** events for off-chain discovery

## 📋 Phase 2: Enhanced Discovery & Scaling (4-6 weeks)

### **CLOB Discovery Architecture**

#### **On-Chain Registry (Active Bids)**
```solidity
// Primary discovery mechanisms
mapping(address => bytes32[]) tokenToBids;        // Token-based lookup  
mapping(address => bytes32[]) userToBids;         // User's active bids
mapping(bytes32 => BidDetails) bidRegistry;       // Complete bid details

struct BidDetails {
    address user;                    // Bidder owner
    address bidderContract;          // Honeypot address
    uint256 hbarAmount;             // HBAR bid amount
    uint256 lazyAmount;             // $LAZY bid amount
    uint256 expiry;                 // Expiration timestamp
    address token;                  // Target NFT collection
    uint256[] serials;              // Empty = any, specific = exact match
    uint256 bidderContractNonce;    // Uniqueness nonce
    bool isActive;                  // Status flag
}
```

#### **Event-Driven Discovery (Off-Chain Indexing)**
```solidity
// Factory events for comprehensive tracking
event BidCreated(bytes32 indexed bidId, address indexed user, address indexed token, BidDetails details);
event BidCancelled(bytes32 indexed bidId, address indexed user);  
event BidExecuted(bytes32 indexed bidId, address indexed executor, uint256 arbitrageProfit);
event BidderContractDeployed(address indexed user, address indexed bidderContract);
```

### **Enhanced Discovery & Analytics**
- **Paginated queries**: Future-proof bid discovery with offset/limit parameters
- **Multi-level analytics**: Token-specific, serial-specific, and global bid views
- **Gas-optimized validation**: Minimal subcalls for bid validity checking
- **Lazy cleanup strategy**: Expired bid removal during natural operations
- **Event consolidation**: Dual-context events (BidderContract + Factory) for comprehensive tracking
