## Fee Structure Implementation

| LSH Token Tier | Platform Fee | Discount |
|---------------|--------------|----------|
| No LSH Tokens | 1.0% | 0% |
| LSH Gen2 | 0.5% | 50% |
| LSH Mutant | 0.25% | 75% |
| **LSH Gen1** | **0.0%** | **100% (FREE!)** |

**Special Cases**:
- $LAZY trades: Always fee-free (enhances token utility)
- Delegated LSH tokens: Count towards fee discounts via LazyDelegateRegistry
